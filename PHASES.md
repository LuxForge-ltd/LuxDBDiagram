## Handoff Notes

- Checks before each pull request: `npm run lint`, `npx vitest run`, `npm run build`, run on joyeuse.
- Baseline before any change (ChartDB 1.21.0 on joyeuse, 2026-11-24): build passed; 842 tests in 109 files passed.
- GitHub Actions is disabled for the repository and ChartDB's workflow files are removed in Phase 01. Do not re-enable them.
- The `upstream` remote points at `chartdb/chartdb` for pulling in future ChartDB changes.
- Version 0.1.0 is set only when the operator says so.
- Pull requests must name the repository explicitly (`gh pr create --repo LuxForge-ltd/LuxDBDiagram`): as a fork, `gh` otherwise targets `chartdb/chartdb`.
- GAP checks: `LUXDB_GAP_SCHEMA_DIR="L:/LuxForge/Grassroots Admin Portal/docs/architecture/schema" npx vitest run src/lib/areas`. On 2026-11-24 the GAP domain files had two broken references, reported to the operator: `finances.dbml` line 78 refers to `match_team_players` (the table is `match_team_player`), and `roles_groups.dbml` line 23 refers to `resource_groups`, which only `gap_combined.dbml` defines.
- Phase 05 notes: the per-Area Float filter (All / Outgoing) was added within the approved Float phase after the GAP test showed `users` in an Area brings 55 single-row Floats (every table's `updated_by`). The default was All at first; the operator chose Outgoing as the default on 2026-11-24 (Phase 07).
- Phase 10 notes: Tailwind's `pink` scale now reads the `--lux-accent-<shade>` CSS variables, so ChartDB's pink classes follow the accent without editing its components; the two hard-coded pink strokes (connection line, temporary floating edge) use `stroke-pink-500`. Purple is the default in `globals.css`; Settings, Accent colour offers ten palettes and stores the choice in local storage (`luxdb-accent-color`). Seen while checking in the browser pane, and not caused by this phase: on a reload while the pane is hidden, ReactFlow's background briefly gets a NaN viewport (console warnings, zoom shows "NaN%") before settling.
- Phase 09 notes: the names live in `src/lib/brand.ts`; a text brand mark (`src/components/brand-mark/`) replaces ChartDB's logo image in the headers and on the examples and templates pages, and those links now go to `/`. Still ChartDB-branded and left for later: the watermark logo drawn on exported images, the small logo in the import instructions, the favicon, and the sidebar's Discord, X and Docs links to ChartDB's community.
